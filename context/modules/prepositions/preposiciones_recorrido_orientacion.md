# Preposiciones de Recorrido y Orientación A2.2

Este taller se enfoca en el **Caso C: Preposiciones de Recorrido y Locales Específicas (A2.2)**, un conjunto de preposiciones esenciales que se introducen al final del nivel A2, particularmente en el segundo cuatrimestre (A2.2). Dominar este grupo es crucial para la habilidad de **orientación en la ciudad** (*Weg beschreiben*) y la descripción de itinerarios.

A diferencia de las *Wechselpräpositionen* (Caso A) y las preposiciones de Destino/Procedencia (Caso B), este grupo se divide en preposiciones que rigen un caso fijo (Dativo o Acusativo) para describir cómo se realiza un desplazamiento o la ubicación relativa.

***

## Taller Intensivo: Preposiciones de Recorrido y Locales Específicas
#### Foco A2.2: Itinerarios y Orientación

### I. Repaso Teórico: Recorrido (Acusativo) y Ubicación Específica (Dativo)

#### 1. Preposiciones de Recorrido Fijo (Acusativo)
Estas preposiciones describen el trayecto o el movimiento alrededor de un objeto, y **siempre rigen Acusativo**.

| Preposición | Caso Fijo | Sentido Local/Direccional | Fuentes |
| :--- | :--- | :--- | :--- |
| **durch** | Acusativo | **"A través de"**. Se usa para recorridos locales, como correr *a través del parque*. | |
| **um** | Acusativo | **"Alrededor de"**. | |
| **bis** | Acusativo | **"Hasta"** (temporal o local). Se usa a menudo en la estructura *bis zu* (Dativo) para destinos. | |

#### 2. Indicaciones Locales Específicas (Dativo Fijo)
Estas estructuras son fundamentales para dar indicaciones y son estudiadas en el nivel A2.2. Notablemente, las estructuras compuestas que indican puntos de referencia o destino **rigen Dativo**.

| Estructura | Caso Fijo | Sentido Local Específico | Fuentes |
| :--- | :--- | :--- | :--- |
| **am ...vorbei** | Dativo | **"Pasar junto a"** (un punto de referencia). | |
| **bis zu** | Dativo | **"Hasta"** (un punto o destino). | |
| **gegenüber von** | Dativo | **"Enfrente de"**. | |

**Nota sobre** ***bis***: Aunque *bis* rige estrictamente Acusativo, cuando se usa para marcar un punto final de un itinerario (*bis zu*), rige Dativo debido a la inclusión de *zu*.

***

### II. Ejercicio Central: Recorridos Fijos (Acusativo)
La práctica principal consiste en aplicar correctamente el artículo en caso acusativo después de las preposiciones *durch* y *um*.

**Instrucción:** Rellene el hueco con la preposición de recorrido (*durch* o *um*) y el artículo o contracción correctos en **Acusativo**.

| Oración | Sustantivo (Género) | Traducción / Sentido | Preposición + Artículo/Contracción |
| :--- | :--- | :--- | :--- |
| 1. Wir laufen $\rule{3cm}{0.15mm}$ (Tunnel, masculino). | Masculino | Corremos a través del túnel. | $\rightarrow$ |
| 2. Sie geht $\rule{3cm}{0.15mm}$ (Stadt, femenino). | Femenino | Ella camina alrededor de la ciudad. | $\rightarrow$ |
| 3. Er fährt $\rule{3cm}{0.15mm}$ (der Park, masculino). | Masculino | Él conduce a través del parque. | $\rightarrow$ |
| 4. Wir spazieren $\rule{3cm}{0.15mm}$ (der See, masculino). | Masculino | Paseamos alrededor del lago. | $\rightarrow$ |
| 5. Das Licht scheint $\rule{3cm}{0.15mm}$ (das Fenster, neutro). | Neutro | La luz brilla a través de la ventana. | $\rightarrow$ |

#### ⚡ Ver las Respuestas (Recorrido Acusativo)
1. Wir laufen **durch den** Tunnel. (Acusativo Masculino: *den*)
2. Sie geht **um die** Stadt. (Acusativo Femenino: *die*)
3. Er fährt **durch den** Park. (Acusativo Masculino: *den*)
4. Wir spazieren **um den** See. (Acusativo Masculino: *den*)
5. Das Licht scheint **durch das** Fenster. (Acusativo Neutro: *das*)

### III. Ejercicio de Consolidación: Indicaciones Locales Específicas (Dativo Fijo)
Estas estructuras son vitales para la habilidad de *Weg beschreiben* (describir el camino) en A2.

**Instrucción:** Complete las oraciones utilizando la estructura de indicación local específica (**am ...vorbei, bis zu, gegenüber von**) y asegúrese de que el sustantivo y el artículo estén en **Dativo** (el caso que estas estructuras rigen). (Asuma *Post* es femenino, *Bahnhof* es masculino, *Polizei* es femenino).

| Oración | Estructura Requerida | Artículo/Contracción en Dativo |
| :--- | :--- | :--- |
| 1. Sie müssen $\rule{3cm}{0.15mm}$ (die Post) **vorbei** gehen. | **am ...vorbei** | $\rightarrow$ |
| 2. Fahren Sie geradeaus $\rule{3cm}{0.15mm}$ (der Bahnhof). | **bis zu** | $\rightarrow$ |
| 3. Das Hotel befindet sich $\rule{3cm}{0.15mm}$ (die Polizei). | **gegenüber von** | $\rightarrow$ |
| 4. Wir treffen ourselves $\rule{3cm}{0.15mm}$ (der Supermarkt, masculino). | **gegenüber von** | $\rightarrow$ |

#### ⚡ Ver las Respuestas (Locales Específicas Dativo)
1. Sie müssen **an der** Post **vorbei** gehen. (*an + der* Dativo Femenino)
2. Fahren Sie geradeaus **bis zum** Bahnhof. (*bis zu + dem* Dativo Masculino $\rightarrow$ *zum*)
3. Das Hotel befindet sich **gegenüber von der** Polizei. (*gegenüber von + der* Dativo Femenino)
4. Wir treffen uns **gegenüber vom** Supermarkt. (*gegenüber von + dem* Dativo Masculino $\rightarrow$ *vom*)

### IV. Desafío de Producción: Creación de un Itinerario (*Weg beschreiben*)
Para practicar la orientación en la ciudad (un tema clave de A2), use las preposiciones de Recorrido (Acusativo) y las Locales Específicas (Dativo) para crear un itinerario corto.

**Instrucción:** Imagine que está dando indicaciones para llegar al "Kino" (cine, neutro). Rellene los huecos usando la preposición y el caso correcto, basándose en la instrucción entre paréntesis.

| Par de Oraciones | Preposición + Sustantivo | ⚡ Ver las Respuestas (Itinerario) |
| :--- | :--- | :--- |
| 1. (Recorrido: *A través de*) | Zuerst gehen Sie $\rule{4cm}{0.15mm}$ (la plaza, *der Platz*, masculino). | Zuerst gehen Sie **durch den** Platz. (*durch* rige Acusativo Masculino) |
| 2. (Indicación local: *Pasar junto a*) | Danach gehen Sie $\rule{4cm}{0.15mm}$ (la iglesia, *die Kirche*, femenino) **vorbei**. | Danach gehen Sie **an der** Kirche **vorbei**. (*am...vorbei* rige Dativo Femenino) |
| 3. (Destino: *Hasta*) | Laufen Sie weiter $\rule{4cm}{0.15mm}$ (el semáforo, *die Ampel*, femenino). | Laufen Sie weiter **bis zur** Ampel. (*bis zu + der* $\rightarrow$ *zur* Dativo Femenino) |
| 4. (Ubicación: *Enfrente de*) | Das Kino liegt $\rule{4cm}{0.15mm}$ (la farmacia, *die Apotheke*, femenino). | Das Kino liegt **gegenüber von der** Apotheke. (*gegenüber von* rige Dativo Femenino) |

### V. Vínculo con Contenidos de A2 y B1
El dominio de las preposiciones del Caso C refuerza el conocimiento en otras áreas de la gramática y el léxico del nivel A2:

1.  **Conexión con el Léxico de Ciudad:** Estas preposiciones se usan con vocabulario relativo a la circulación por la ciudad, medios de transporte, y lugares urbanos como *der Bahnhof* (estación de tren), *die Ampel* (el semáforo), *die Straße* (la calle) y *der Platz* (la plaza), que son léxico clave para desenvolverse en la ciudad.
2.  **Declinación Fija:** El uso de *durch* y *um* requiere declinar en Acusativo, mientras que las estructuras *am...vorbei, bis zu, gegenüber von* requieren la declinación en **Dativo**. Esto es una práctica constante de las formas de los artículos determinado, indeterminado, posesivos y de negación en Dativo y Acusativo.
3.  **Verbos Auxiliares:** Muchos de los verbos de movimiento utilizados en estos itinerarios (*gehen, laufen, fahren*) requieren el auxiliar **sein** para formar el *Perfekt*.
4.  **No Confundir con *Wechselpräpositionen***: Es fundamental recordar que estas preposiciones **no** siguen la regla de *Wo?* (Dativo) vs. *Wohin?* (Acusativo) de las *Wechselpräpositionen* (Caso A). Por ejemplo, *durch* siempre rige Acusativo, incluso si el verbo indica movimiento.
