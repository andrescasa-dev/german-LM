# Preposiciones de Doble Caso: *Wechselpräpositionen* (Nivel A2)

Este taller se centra exclusivamente en el **Caso A: *Wechselpräpositionen*** (Preposiciones de Doble Caso), que son un grupo de nueve preposiciones cuya dificultad principal radica en que el **caso gramatical** que rigen (Dativo o Acusativo) depende del **tipo de acción** que acompaña al verbo.

## Taller Intensivo: *Wechselpräpositionen*
*(Doble Caso: Movimiento vs. Ubicación, Nivel A2)*

### I. Repaso Teórico: La Regla Central y las Nueve Preposiciones

#### 1. La Regla de Oro

Las **Wechselpräpositionen** (preposiciones de cambio) rigen un caso u otro en función de si expresan **ubicación estática** o **movimiento direccional**. Es importante recordar que las preposiciones en alemán determinan el caso gramatical del sustantivo, artículo, adjetivo o pronombre subsiguiente.

| Concepto | Pregunta Clave | Caso Gramatical | Descripción de la Acción | Fuentes |
| :--- | :--- | :--- | :--- | :--- |
| **Ubicación** | **Wo?** (¿Dónde?) | **Dativo** | Indica una posición estática o un estado (quedarse, estar situado). | |
| **Movimiento** | **Wohin?** (¿Hacia dónde?) | **Acusativo** | Indica dirección o desplazamiento (ir, colocar, sentar). | |

#### 2. El Grupo de las Nueve *Wechselpräpositionen*

Las nueve preposiciones que funcionan con esta regla dual son:

1.  **an**: junto a, pegado a
2.  **auf**: sobre, encima de
3.  **hinter**: detrás de
4.  **in**: dentro de, en
5.  **neben**: al lado de
6.  **über**: sobre (sin contacto)
7.  **unter**: debajo de
8.  **vor**: delante de
9.  **zwischen**: entre

***

### II. Diferenciación por Verbos y Pares Esenciales

Para aplicar la regla, es fundamental identificar el verbo que indica si la acción es de posición estática (Dativo) o de movimiento (Acusativo). El nivel A2/B1 requiere memorizar los pares de verbos que significan "estar situado" (Dativo) o "colocar/poner" (Acusativo) .

| Posición Estática (Dativo) | Movimiento Direccional (Acusativo) | Significado | Fuentes |
| :--- | :--- | :--- | :--- | :--- |
| **liegen** | **legen** | Estar situado horizontalmente / Colocar acostado  |  |
| **stehen** | **stellen** | Estar situado verticalmente / Colocar verticalmente  |  |
| **sitzen** | **setzen** | Estar sentado / Sentar (a alguien/algo)  |  |
| *bleiben* | *gehen/fahren* | Permanecer / Ir/Conducir | |
| *sein* | *kommen* | Ser/Estar (ubicación) / Venir | |

**Ejemplo Práctico de Contraste**:

*   **Posición (Dativo):** *Der Bleifstift **liegt** **unter dem** Tisch.* (El lápiz está situado bajo la mesa).
*   **Movimiento (Acusativo):** *Ich **lege** den Bleifstift **unter den** Tisch.* (Coloco el lápiz bajo la mesa).

### III. Ejercicio Central: Elección de Caso (Dativo o Acusativo)

**Instrucción:** Lea cada oración, identifique si el verbo indica **Posición (Dativo)** o **Movimiento (Acusativo)**.

| Oración | Verbo Clave | ¿Movimiento (Acusativo) o Posición (Dativo)? |
| :--- | :--- | :--- |
| 1. Wir **gehen** in ____ (Park, masculino). | $\rightarrow$ | Movimiento / Posición |
| 2. Das Bild **hängt** über ____ (Sofa, neutro). | $\rightarrow$ | Movimiento / Posición |
| 3. Ich **stelle** die Schuhe unter ____ (Bett, neutro). | $\rightarrow$ | Movimiento / Posición |
| 4. Der Ball **ist** zwischen ____ (zwei Bäume, plural). | $\rightarrow$ | Movimiento / Posición |
| 5. Sie **sitzen** an ____ (Fenster, neutro). | $\rightarrow$ | Movimiento / Posición |
| 6. Er **fährt** auf ____ (Platz, masculino) . | $\rightarrow$ | Movimiento / Posición |
| 7. Wir **bleiben** in ____ (Museum, neutro) . | $\rightarrow$ | Movimiento / Posición |

#### ⚡ Ver las Respuestas (Caso)

1.  **gehen** $\rightarrow$ **Movimiento (Acusativo)**.
2.  **hängt** (estar colgado) $\rightarrow$ **Posición (Dativo)** .
3.  **stelle** (colocar verticalmente) $\rightarrow$ **Movimiento (Acusativo)**.
4.  **ist** (ser/estar) $\rightarrow$ **Posición (Dativo)**.
5.  **sitzen** (estar sentado) $\rightarrow$ **Posición (Dativo)** .
6.  **fährt** (conducir/viajar) $\rightarrow$ **Movimiento (Acusativo)**.
7.  **bleiben** (permanecer) $\rightarrow$ **Posición (Dativo)**.

### IV. Ejercicio de Consolidación: Artículos y Contracciones

El siguiente paso es aplicar el artículo o contracción correcto (ej., **in + dem = im** (Dativo); **in + das = ins** (Acusativo); **an + dem = am** (Dativo); **an + das = ans** (Acusativo)).

**Instrucción:** Rellene el hueco de las frases anteriores con la preposición + artículo o contracción correctos.

| Oración | Caso (Dat. / Acus.) | Género del Sustantivo | Preposición + Artículo/Contracción |
| :--- | :--- | :--- | :--- |
| 1. Wir gehen **in** ____ Park (m). | Acusativo | Masculino | $\rightarrow$ **in den** |
| 2. Das Bild hängt **über** ____ Sofa (n). | Dativo | Neutro | $\rightarrow$ **über dem** |
| 3. Ich stelle die Schuhe **unter** ____ Bett (n). | Acusativo | Neutro | $\rightarrow$ **unter das** |
| 4. Der Ball ist **zwischen** ____ zwei Bäume (pl.). | Dativo | Plural | $\rightarrow$ **zwischen den** |
| 5. Sie sitzen **an** ____ Fenster (n). | Dativo | Neutro | $\rightarrow$ **an dem / am** |
| 6. Er fährt **auf** ____ Platz (m). | Acusativo | Masculino | $\rightarrow$ **auf den** |
| 7. Wir bleiben **in** ____ Museum (n) . | Dativo | Neutro | $\rightarrow$ **in dem / im** |

#### ⚡ Ver las Respuestas (Artículos y Contracciones)

1. Wir gehen **in den** Park. (Acusativo Masculino: *den*)
2. Das Bild hängt **über dem** Sofa. (Dativo Neutro: *dem*)
3. Ich stelle die Schuhe **unter das** Bett. (Acusativo Neutro: *das*)
4. Der Ball ist **zwischen den** zwei Bäumen. (Dativo Plural: *den...n*)
5. Sie sitzen **an dem** Fenster / **am** Fenster. (Dativo Neutro: *dem / am*) 
6. Er fährt **auf den** Platz. (Acusativo Masculino: *den*)
7. Wir bleiben **in dem** Museum / **im** Museum. (Dativo Neutro: *dem / im*)

El mayor desafío para el estudiante de A2/B1 es usar pares de verbos para expresar la misma relación espacial, pero alternando el caso.

### VI. Vínculo con Otros Temas de A2/B1

Dominar las *Wechselpräpositionen* es esencial ya que se entrelazan con otros aspectos fundamentales de los niveles A2/B1 :

1.  **Declinación:** La elección del caso (Dativo o Acusativo) rige directamente la declinación de los artículos (determinados, indeterminados, posesivos y de negación *kein*) , así como las terminaciones del adjetivo . Por ejemplo, en el ejercicio, el artículo cambia de *dem* (Dativo masculino) a *den* (Acusativo masculino) dependiendo de si hay posición o movimiento.
2.  **Indicaciones Locales:** Estas preposiciones proporcionan el marco gramatical para el vocabulario local y direccional (como *der Park*, *das Kino*) que se practica intensamente en A2 para orientarse en la ciudad.
3.  **Verbos Fijos:** Es crucial evitar la confusión con los verbos que rigen preposición fija, ya que en estos casos la **regla de movimiento/ubicación no se aplica** y la preposición mantiene un caso fijo (como *denken an + Acusativo* o *warten auf + Acusativo*) .
